# Graphite redesign — progress

The working trace of `redesign-plan.md`. Each task has a status, the files it touched and a resume
note. Update it at the end of every task: subagents update their own row, and the orchestrator
marks a task verified.

Status: `todo` · `doing` · `done` (by the worker) · `verified` (checked by the orchestrator:
build, tests, screenshots, release binary rebuilt).

Designs: `docs/design/redesign-brief/designs/*.dc.html`. Open them with headless chromium,
which must run their JS (`--virtual-time-budget=5000`). Their text is in `designs/text/*.txt`.
Briefs: `redesign-brief/PROMPT.md` (shell) and `PROMPT-devices.md` (devices).

Checks for every task:
- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test -p <touched crates> --release`
- app UI work also renders screenshots:
  `CADENZA_SCREENSHOT_DIR=dir cargo test -p cadenza-app --release --test ui -- --ignored <filter>`
